# CSV Viewer

CSV を見るためのアプリ。macOS 向け。編集はしない（閲覧専用）。

## 目指すこと

優先度の高い順。

1. **小さな CSV を、最速で開く。**
2. **巨大な CSV（GB 単位）も、開いて使える。** 全部を読み終えるのを待たずに、先頭から見られる。
3. **日本語を、そのまま扱える。** 文字コードは自動で判定し、手動でも切り替えられる。
4. **速い SSD や大きなメモリに頼らない。** 一般的な PC でも、困らない速さにする。

## 方針

- **全部を読み込まない。** 大きなファイルは、必要な部分だけを読む。メモリの使用量を、ファイルの大きさに比例させない。
- **編集を前提にしない。** 閲覧に最適な作りにするため、編集機能は想定していない。
- **文字コードは、自動で判定する。** 判定が間違っていても、利用者が選び直せる。
- **速度は、測って決める。** 計測用のプログラムを `examples/` に置いている。性能の話は、推測ではなく計測で行う。

## 使い方

```sh
cargo run --release -- path/to/file.csv
```

ファイルは、次のどれでも開ける。複数を同時に開くと、1つにつき1ウィンドウになる。何も開いていないウィンドウがあれば、そこに開く。

- コマンドの引数
- メニューの `File > Open…`
- ウィンドウへのドラッグ＆ドロップ
- Finder の「このアプリケーションで開く」（`.app` にした場合）

操作とショートカットは、メニューを見る。

## アプリ（.app）にする

```sh
scripts/bundle.sh
cp -R "target/bundle/CSV Viewer.app" /Applications/
```

置いたあとは、普通のアプリと同じに使える。Launchpad から起動できるし、Finder の「このアプリケーションで開く」にも出る（`~/Applications` でもよい）。
署名は ad-hoc で、手元で使う分には動く。配布用の署名や公証はしていない。

## 設定

表示の設定は、次のファイルに保存される。コメントを書ける JSON（JSONC）で、手で編集してもよい。
アプリが保存し直すときに、コメントは消える。

```
~/Library/Application Support/net.naoki-workspace.csv-viewer/settings.jsonc
```
